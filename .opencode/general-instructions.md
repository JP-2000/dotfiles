# General Coding Instructions

- Write Simple and Readable code, its okay if it takes more lines.
- Make the smallest correct change that solves the request.
- Inspect the existing code and nearby conventions before editing.
- Preserve existing project structure, naming, formatting, and style unless the task explicitly calls for a change.
- Prefer simple, readable code over new abstractions; only add helpers when they are reused or clarify complex logic.
- Keep changes focused on the user's request, and do not modify unrelated files or user changes.
- Add comments sparingly, only when they explain non-obvious behavior or important constraints.
- Do not write tests unless explicitly mentioned.
